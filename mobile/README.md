# EduCore Mobile

Flutter client for the EduCore Laravel API.

## Run

```bash
flutter pub get
flutter run
```

Android emulator requests Laravel through `http://10.0.2.2:8000/api`.

Demo student account: `murid@educore.test` / `password`.
